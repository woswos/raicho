# Raicho deployment

Run these from the repository root on a Linux Docker host. Each target acts on
one deployment, chosen by RAICHO_PROJECT, then COMPOSE_PROJECT_NAME, then
"raicho". RAICHO_PORT (8080), RAICHO_ADMIN_PORT (6080), and RAICHO_VNC_PORT
(5900) set loopback ports.

# Start and stop
  make deploy-up      Build the runtime images (make images), then run
                      docker compose up -d --wait. Starts or upgrades the
                      deployment and prints http://127.0.0.1:8080.
  make deploy-admin   deploy-up plus compose.admin.yaml, which opens the
                      Thunderbird desktop in a browser on 127.0.0.1:6080 and
                      to VNC viewers on 127.0.0.1:5900. Run
                      make deploy-up to close it again.
  make deploy-restart docker compose restart, for every service or for
                      SERVICE=raicho, gateway, or thunderbird. Rebuilds and
                      recreates nothing, so the admin desktop stays open.
  make deploy-down    docker compose down. Keeps the volumes.

# Inspect
  make deploy-ps      docker compose ps. Lists the running containers.
  make deploy-health  Read /api/status without stopping anything: readiness,
                      connector state, heartbeats, and the deployed commit
                      against this checkout. Fails unless connected.
  make deploy-logs    docker compose logs with timestamps. SERVICE= picks one
                      service and FOLLOW=1 keeps streaming.
  make deploy-shell   A shell inside SERVICE=raicho, gateway, or thunderbird.
  make deploy-vnc     Open vncviewer on this computer to the desktop that
                      make deploy-admin publishes.

# Connector credentials
  make deploy-connector-<command>
      Build the runtime images, then run
      bash deploy/credentials/connector.bash <command>, where <command> is
      init, rotate, verify, status, revoke, or reactivate. init enrolls the
      connector and waits for an authenticated heartbeat.
  Once .raicho/<project>/credentials/ exists, deploy-up and deploy-admin add
  compose.credentials.yaml and RAICHO_CREDENTIAL_DIRECTORY themselves.

# Remove
  make deploy-clean   List the deployment and ask you to type its name, then
                      delete its containers, networks, volumes (including the
                      Thunderbird profile), and .raicho/<project>/, and run
                      everything make clean does.

Add VERBOSE=1 for Docker progress. Details: docs/operations/local-runtime.md
and docs/operations/connector-credentials.md.
